# Johnny Builds to Mars

An interactive, kid-friendly picture book made with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or serve the folder with any static file server.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the repository's main branch and `/ (root)`, then save.

There is no build step and no external dependency. All illustrations, interactions, and sounds are generated in the browser.
